## 当前范围

登录后，Bunch 文稿、批注、画布图片与关系自动保存到 Supabase；页面显示云端保存状态。独立的非 Bunch 文稿仍保存在当前浏览器。

在 Bunch 总览点击「分享与成员」，创建者可生成 7 天有效的可查看/可编辑邀请链接、停用链接、调整成员权限或移除成员。接收者需要登录后加入。停用链接不自动移除已经加入的成员。

成员在线时，其他人的保存会通过 Supabase Realtime 自动送达并更新当前页面；实时消息只广播文稿编号和版本，正文仍由现有成员权限控制的数据库读取。保存采用版本校验，发生冲突时保留本机内容，可先导出本机副本再载入云端版本。单个 Bunch 上限 8 MB。

目前使用 Supabase 默认测试邮件服务；测试请使用该 Supabase 组织成员邮箱。正式开放其他人注册前需要配置自定义 SMTP。当前不启用付费发信，也不取消邮箱验证。

## 初始化与维护

001-account.sql、002-bunch-cloud.sql 和 003-bunch-realtime.sql 已在现有 Supabase 项目执行，分别建立账户资料/头像权限、Bunch 云端数据/邀请/成员权限与实时更新信号。只有成员能读取 Bunch，只有创建者和编辑成员能写入，只有创建者可管理成员和邀请。共同参与 Bunch 的成员可读取彼此的显示资料。

网页内仅包含公开项目 URL 与 Publishable key，不得加入 service_role、secret key 或数据库密码。

本地旧文稿不会随网站发布自动上传，请先在原本地页面导出，然后在新网站导入。
